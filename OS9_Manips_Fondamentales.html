Utilisation et modèle

Choisir une scène, régler la préparation puis lancer la lecture. Pause fige l’évolution ; Réinitialiser retrouve le cas de départ. Les détections sont des tirages simulés suivant les lois indiquées.

Projection masque les réglages et agrandit les lectures. ⛶ active le plein écran indépendamment. Image enregistre la scène courante en PNG. Prévoir masque les lectures principales, puis Révéler les affiche ; le dessin reste visible.

Raccourcis : espace = lecture/pause ; R = réinitialiser ; P = projection. Zoom et Cadrer agissent sur le dessin sans modifier les paramètres physiques. Les liens de référence demandent une connexion ; l’animation fonctionne entièrement hors connexion.

Conception : ressources pédagogiques d’E. Guillaume · MPSI · OS9. Modèles et conventions explicités pour chaque scène.
