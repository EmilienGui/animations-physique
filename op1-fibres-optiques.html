Guider la lumière, transmettre un signal

Trois expériences. Guider un rayon : orienter le laser, afficher les angles puis le cône d’acceptance. Comparer : les mêmes cinq angles sont injectés dans les deux fibres. Transmettre : envoyer une ou deux impulsions et observer leurs arrivées ; « Voir les arrivées » avance l’horloge jusqu’à la fenêtre de réception.

Manipulations. Dans la coupe, déplacer le laser ou utiliser les flèches haut/bas, avec Maj pour un pas de 5°. Les curseurs et champs numériques sont équivalents. + et − changent le segment visible ; Cadrer restaure la vue. Projection masque les réglages. Clair/Sombre adapte toute la scène et les exports. Espace : pause ; R : recommencer ; F : plein écran.

Échelles. La coupe locale utilise la même échelle sur les deux axes : ses angles sont fidèles. La vue d’ensemble comprime seulement z et annonce le facteur : ne pas y mesurer les angles. Ces vues montrent un court segment, dont la longueur est indiquée, et non la fibre entière de longueur L. La perspective explique seulement la structure ; l’épaisseur de gaine est conventionnelle. Les teintes codent l’indice, pas une couleur réelle ou une absorption.

Propagation. Fibre droite cylindrique ; rayons méridiens ; indices non dispersifs. Dans le cœur à saut d’indice, n = nc. Dans le gradient, n²(y) = nc² − (nc² − ng²)y²/a². Les trajectoires du gradient sont calculées à partir de l’invariant k = n cos θ′, sans approximation paraxiale. La vitesse locale est c/n et le temps est l’intégrale ∫ n ds/c. Les rayons guidés se courbent continûment dans le gradient, sans réflexions successives sur des couches fictives. Le rayon limite est distingué d’un rayon strictement guidé.

Transmission. Les cinq angles vont de 0 à θ, avec des poids égaux fixés à 1/5 par rayon injecté. Les rayons ayant quitté le cœur avant la sortie sont exclus de la réception ; un rayon axial peut être reçu même sans contraste d’indice, sans être confiné. Chaque impulsion est une gaussienne, de largeur à mi-hauteur réglable. Les courbes représentent la somme de copies retardées de cette gaussienne, sans interférences, polarisation ni calcul de modes ou de puissances de couplage. La dispersion affichée est l’écart des temps parmi les rayons reçus échantillonnés, pas nécessairement l’écart maximal de la fibre.

Lire les chronogrammes. Les pointillés donnent l’impulsion d’entrée décalée de τréf = ncL/c. L’abscisse est t − τréf et les deux fibres utilisent les mêmes échelles. La somme des poids injectés vaut 1 ; la hauteur reçue peut diminuer par étalement ou exclusion de rayons ayant quitté le cœur. Les rangées « Avancement » montrent la vraie coordonnée z/L de chaque rayon, sur des lignes séparées pour la lisibilité : ce ne sont pas des trajectoires géométriques.

Limites. Pas d’absorption, de courbure de fibre, de dispersion chromatique, de coefficients de Fresnel ni d’onde évanescente. Le modèle de rayons ne décrit pas le caractère monomode d’une fibre. Le profil quadratique de n² réduit fortement la dispersion dans le régime de faible contraste ; les temps ne sont pas forcés à être identiques. Le seuil théorique à saut d’indice correspond à une limite des rayons guidés.
