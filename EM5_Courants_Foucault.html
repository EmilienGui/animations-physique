Commandes communes

La lecture suit le temps physique, multiplié par le facteur indiqué. Pause arrête simultanément le mouvement et les courbes. Lorsque le préaffichage est actif, les courbes pâles montrent l’évolution complète calculée ; les traits appuyés suivent le temps déjà parcouru. Glisser sur les courbes ou utiliser le curseur permet de choisir un instant. Un changement de paramètre prépare une nouvelle expérience, à l’arrêt.

La molette et les boutons − / + règlent le zoom. Maj + glisser déplace le cadrage ; Cadrer rétablit la vue entière. Les légendes gardent leur taille lors du zoom. Le graphique dispose de son propre cadrage temporel. Sur fenêtre étroite, Réglages ouvre un panneau depuis le bord droit.

Projection masque les réglages et agrandit les informations. Le petit carré ⛶ commande séparément le plein écran. Image enregistre la scène, les courbes et les valeurs dans une image PNG. Espace : lecture/pause ; ← / → : parcourir le temps ; R : recommencer ; F : plein écran ; Échap : fermer l’aide ou le panneau de réglages.
