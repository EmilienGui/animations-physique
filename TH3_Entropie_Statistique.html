Des microétats à l’entropie

Les trois vues relient le pile ou face du cours à la répartition gauche / droite d’un gaz. Les paramètres restent à droite ; les gestes sur les dessins disposent de commandes équivalentes. Espace : lecture / pause.

Pièces et comptage

Un microétat précise l’état individuel de chaque pièce repérable. Le macroétat retient seulement le nombre k de piles. Pour N objets indépendants à deux possibilités équiprobables, Ω(k) = C(N,k), P(k) = Ω(k)/2ᴺ. Les tirages sont pseudo-aléatoires indépendants ; les manipulations manuelles ne sont pas ajoutées à l’histogramme des tirages.

Pour N ≤ 10, toutes les configurations compatibles avec le macroétat sélectionné sont accessibles dans la liste. Cliquer sur une colonne choisit un exemple de ce macroétat. Pour N > 10, le comptage est calculé sans énumérer les configurations. Au-delà de 160 pièces, seules 160 sont dessinées ; le comptage et les tirages portent sur l’effectif entier.

Particules

Modèle de points indépendants dans un rectangle 2D, réflexions élastiques sur les parois, vitesses initiales gaussiennes. Il n’y a ni interaction entre particules ni calcul de pression ou de température thermodynamique : cette vue sert uniquement à étudier les occupations gauche / droite. Les rayons dessinés sont visuels, sans volume exclu. Tous les points (jusqu’à 1000) sont simulés et comptés ; au plus 250 sont dessinés.

Avant l’ouverture, tous les points sont dans la moitié gauche. Retirer la cloison ne leur impose aucune direction. Les points suivent leurs trajectoires ; les fluctuations de N gauche restent visibles. La référence binomiale est celle d’une observation d’équilibre de N positions indépendantes uniformément distribuées. Elle ne décrit pas le transitoire initial.

L’histogramme temporel est relevé après un délai τ = 8, tous les Δτ = 0,4, pour écarter le début du transitoire. Ces observations restent corrélées ; leur fréquence ne doit pas être interprétée comme celle de tirages indépendants, ni comme la preuve d’une equilibration exacte à τ = 8. τ est un temps réduit de ce modèle, sans unité SI revendiquée. Les collisions entre particules et la thermalisation d’un gaz réel ne sont pas modélisées.

Cliquer sur l’histogramme ou choisir k sélectionne un macroétat à étudier, sans déplacer les particules. La valeur actuelle N gauche est affichée dans la scène. Le choix « Tout à gauche » prépare physiquement l’état initial seulement après Réinitialiser ; il ne reconcentre jamais spontanément le gaz.

Entropies à distinguer

SB(k)/kB = ln C(N,k) désigne ici la contribution du comptage gauche / droite pour un macroétat fixé ; positions détaillées et vitesses ont été éliminées de cette description. Ce n’est pas l’entropie thermodynamique absolue du gaz. Une baisse temporaire de ce comptage dans un petit système fluctuant n’est pas supprimée.

Pour la détente d’un gaz parfait dans le vide du volume V au volume 2V, le nombre total d’états de position accessibles est multiplié par 2ᴺ : ΔS = NkB ln 2 = nR ln 2. Ce rapport compte tous les états accessibles, pas seulement le macroétat exact k = N/2. Les deux expressions ne sont pas identifiées.

À grand N

Lire retire la cloison et anime la détente ; Pause, Un pas, Réinitialiser et la vitesse restent disponibles. Changer N prépare un nouvel état initial. Le dessin passe de toutes les particules pour N ≤ 4000 à un échantillon de 20 000 points pour un million, puis jusqu’à 32 000 points pour les effectifs macroscopiques. Les mêmes points suivent des trajectoires avec réflexions élastiques.

Au-delà de 4000 particules, les fluctuations de l’échantillon dessiné ne sont pas utilisées comme celles du gaz entier. La fraction moyenne à gauche est calculée séparément pour le modèle de points indépendants, initialement uniformes dans la moitié gauche, avec vitesses gaussiennes et réflexions aux parois. Le trait orange du diagramme suit cette moyenne ; jusqu’à N = 4000, il suit la fraction effectivement comptée. La courbe bleue et les trois valeurs statistiques sont des références d’équilibre calculées pour N. La variation d’entropie affichée est celle de la détente complète.

La moyenne est N/2 et l’écart-type de N gauche est √N/2. L’écart-type de la fraction N gauche / N vaut 1/(2√N) : les fluctuations absolues augmentent, mais leur importance relative diminue. La représentation centrée utilise z = (N gauche − N/2)/(√N/2). Pour N > 1000, elle montre l’approximation normale au voisinage de l’équilibre ; cette approximation n’est pas utilisée pour les queues extrêmes.

À l’équilibre, P(toutes à gauche) = 2⁻ᴺ exactement dans le modèle indépendant. Cette probabilité à un instant ne donne pas un temps de retour : l’atelier n’en déduit aucun délai.

La même détente, deux descriptions

Un gaz parfait est initialement confiné dans la moitié d’une enceinte rigide et adiabatique. On retire la cloison : le volume accessible double.

Q = W = 0   ⇒   ΔU = 0   ⇒   Tf = Ti

Le nombre total d’états de position accessibles est multiplié par 2ᴺ, à énergie inchangée :

ΔS = kB ln(2ᴺ) = NkB ln 2 = nR ln 2.

Il s’agit du rapport de tous les états accessibles après et avant la levée de contrainte. Le coefficient C(N, N/2) ne compte qu’une répartition exacte et ne lui est pas substitué.

Dans le bilan macroscopique, S échangée = 0 et S créée = ΔS. Une détente isotherme réversible entre les mêmes états donnerait la même ΔS, entièrement échangée.
