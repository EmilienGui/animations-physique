Cliquez sur une raie du spectre, ou choisissez une composante dans la liste, pour suivre son amplitude et sa phase. La moyenne est placée dans une zone distincte, hors de l’axe logarithmique.

Conventions et limites

e(t) = E₀ + Σ Eₙ cos(2πfₙt + φₑ,ₙ). Chaque coefficient complexe est multiplié par H(j2πfₙ). Une phase est indéfinie pour une amplitude nulle. Un gain supérieur à 1 aux bornes d’un dipôle réactif ne signifie pas que le circuit passif fournit une amplification de puissance.

RC : f₀ = f꜀ = 1/(2πRC). RLC : f₀ = 1/(2π√LC), Q = √(L/C)/R. La coupure à −3 dB est relative au maximum du gain : en présence d’une résonance marquée, une bande autour du pic peut apparaître. Les asymptotes sont les limites BF/HF, parfois éloignées de la courbe pour Q petit ou grand. Le coupe-bande a deux bandes passantes, séparées par une bande de rejet.

Les séries de Fourier sont tronquées au rang indiqué : le créneau reconstruit présente l’effet de Gibbs près des discontinuités. Les courbes temporelles emploient la même somme finie en entrée et en sortie. Le parasite proposé est une sinusoïde déterministe, pas un bruit aléatoire. Si son rapport de fréquences est irrationnel, la somme n’est pas périodique ; la superposition reste valable.

La comparaison « sans déphasage » conserve les gains mais supprime volontairement les déphasages du filtre sur les composantes alternatives. L’approximation temporelle compare le calcul exact à l’intégration ou la dérivation asymptotique ; ses conditions et son coefficient sont indiqués sous le graphe. Pour le passe-bas, l’intégration porte sur e − E₀ et la moyenne est conservée.

Cascade

Générateur idéal, sortie finale ouverte, R₁ = R, C₁ = C, R₂ = kR et C₂ = C/k. Sans suiveur : H = jx / [1 − x² + j(2 + 1/k)x]. Avec un suiveur idéal en régime linéaire : H = jx / [1 − x² + 2jx], x = f/f₀. La courbe en pointillés représente toujours le produit des fonctions de transfert à vide. Les impédances et le courant d’entrée du second étage expliquent l’écart ; un grand k le réduit.

Composants idéaux, C = 100 nF pour déterminer les autres valeurs affichées ; valeurs choisies pour le modèle, sans restriction aux séries commerciales. ALI idéal : aucune saturation, bande passante finie ni limitation de courant simulée.

Raccourcis : Espace lire/pause ; P projection ; C cadrer. Le mode Projection masque les réglages ; le plein écran est une commande distincte. « Image » exporte les vues dans le thème courant.
